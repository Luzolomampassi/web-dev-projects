# Boostify

Página institucional estática da Boostify.

## Estrutura

- `inicio.html`: conteúdo e estrutura da página.
- `style.css`: estilos, organizados por secção e por tamanho de ecrã.
- `main.js`: menu para dispositivos móveis e navegação dos depoimentos.
- `.hintrc`: configuração das verificações HTML/CSS.

## Abrir o projeto

Abre `inicio.html` diretamente no navegador. O projeto não precisa de instalação
de dependências nem de um servidor para apresentar a página.
